# 法务操作说明书

> 写给法务部同事。你不需要任何开发经验，只要会打开 zcode、会打字就行。
> 如果遇到本说明书没覆盖的问题，把屏幕上看到的提示原文发给 IT，不要自己改代码或配置。

---

## 一、我们装了哪两个技能

| 技能 | 中文名 | 一句话作用 |
|---|---|---|
| `legal-company-query` | 企业风险查询 | 你说一个公司名，它帮你查这家公司的工商信息和风险等级，并生成一份 Excel |
| `legal-approval-risk` | 合同审批风险预警 | 合同审批一提交，先核对**合同文件里的签约对方**和表单选的企业是不是同一家（不是同一家会**自动拒绝退回**给提交人）；是同一家才查风险：评级回填到表单【企业风险评级】、Excel 报告（命中风险黄色高亮）附到「风险报告附件」，然后放行给法务 |

两个技能都接企查查，查的是真实企业数据。

---

## 二、第一次用之前

这些**只需要做一次**，一般由 IT 帮你弄好：

1. 电脑装好 zcode 并登录。
2. 电脑装好 Python 3.11（没有就让 IT 装，按《配置说明》里的步骤，勾选 Add to PATH）。
3. 两个技能已经在 zcode 的「技能」页里出现（IT 用 GitHub 地址装的）。
4. 每个技能文件夹里有一份填好的 `.env`（IT 私下发给你，**不要外传**）。
5. 合同审批风险预警需要飞书管理员做一次性准备：在合同审批流里加一个「系统风险预审」节点（审批人＝预审员工账号，排在法务节点之前），并把【企业风险评级】和「风险报告附件」两个控件在该节点设为可编辑；IT 把预审账号 ID 写进该技能的 `.env`。详见第四节。

如果技能页里没看到这两个技能，或 `.env` 没到位，先找 IT，不要自己猜。

## 三、企业风险查询（legal-company-query）

### 什么时候用

- 签约前想了解一家公司靠不靠谱
- 想看一家公司的工商信息、三要素是否一致、有没有涉诉/失信/被执行
- 同事问「这家客户能合作吗」

### 怎么说

直接在 zcode 对话里用自然语言说就行，例如：

- 「查一下上海帮麦麦网络科技有限公司的风险」
- 「这个客户靠谱吗：成都白兔有你文化传播有限公司」
- 「帮我看看这家企业的风险：xxx」

### 你会看到什么

1. **如果公司名有重名**：会先列出几个候选公司（带编号、信用代码、法人、状态），你回复一个编号选定。
2. **选定后**：会告诉你这家公司的——
   - 名称、统一社会信用代码、法定代表人、登记状态
   - 三要素是否一致（一致 / 不一致 / 未核验）
   - 风险等级：**低 / 中 / 高 / 未知**
   - 命中了哪些风险项（一条条列出）
   - 本次花了多少钱（已查过的一般 0 元，新查约 7.5 元）
3. **Excel**：会自动生成一份 `qcc_公司名_时间.xlsx`，放在本机技能目录里。你直接打开看明细。

### 几个要点

- **同名公司**：先选编号，别选错。
- **想查最新数据**：说「重新查」「查最新」「刷新一下」，会强制拉最新（约 7.5 元）。
- **已查过的公司**：默认用上次结果，不花钱；想看最新就说「查最新」。
- **Excel 路径**：结果里会给完整路径，找不到就让 IT 帮你打开。

## 四、合同审批风险预警（legal-approval-risk）

### 什么时候用

- 你希望合同审批一提交，就自动有风险提示
- 想让法务在审批单里直接看到对方公司的风险评级和报告

### 它怎么工作

这个技能是**自动跑**的（定时轮询，也可以随时手动跑一次）。它会：

1. 扫描飞书里派给**预审账号**的合同审批待办（「系统风险预审」节点）。
2. 读表单里已选好的对方（客户名称 / 供应商名称 / 达人企业名称，三者必现其一）。
3. **先核对合同主体**：下载审批单里的合同附件（Word 或 PDF 都行），找出合同里**实际签约的对方**，和表单选的企业比对。
   - **不是同一家**（包括合同其实是和个人签的）→ **自动拒绝退回**，提交人会收到飞书通知和修改提示，改对后重新提交即可；这一步不花钱。
   - **是同一家** → 继续下一步。
   - **核对不了**（附件缺失、是扫描件或图片）→ 放行并在评级栏写「合同主体未能自动校验，请法务人工核对」，请人工打开合同确认。
4. **对方是自然人**（个人）：直接回填「自然人无须评估风险」，不查企查查、不花钱。
5. 对方是公司：先查内部存档（90 天内查过的 0 元），没有才查企查查最新（约 7.5 元）。
6. 把评级写进表单【企业风险评级】、Excel 报告附到「风险报告附件」控件，然后**自动同意放行**给下一个审批节点（法务）。

### 审批单里会看到什么

| 位置 | 内容 |
|---|---|
| 【企业风险评级】 | `高风险，详见风险报告附件` / `中风险，详见风险报告附件` / `低风险` / `未知（未查得风险数据）` / `自然人无须评估风险` / `合同主体未能自动校验，请法务人工核对` |
| 「风险报告附件」 | 一份 Excel，**命中风险的行整行黄色高亮**（概要区有图例）；低/中/高风险都会附 |
| 审批评论（放行时） | `风险预审完成：<评级>，自动放行` |
| 审批评论（拒绝时） | `风险预审拒绝：合同签约对方为「X」，与表单供应商名称「Y」不一致，请核对修改后重新提交（未查询企业风险）`——提交人同时会收到飞书拒绝通知 |

**注意**：这两个位置是 AI 专属的。如果提交人误写/误传了内容，预审时会**一并删除**，只保留 AI 写入的评级和报告。

### 飞书侧一次性准备（管理员 / IT）

1. 在合同审批定义里新增「系统风险预审」节点：审批人 = 预审员工账号，排在法务节点之前。
2. 在该节点把【企业风险评级】设为**非必填 + 可编辑**；新增附件控件「风险报告附件」（控件名完整包含"风险报告附件"即可，括号里的说明可随意），设为**可编辑**。
3. IT 把预审账号的飞书 ID 写入技能 `.env` 的 `FEISHU_APPROVER_USER_ID`（`_TYPE` 配成 `user_id` 或 `open_id`）。
4. 应用权限按《飞书应用权限开通指南》开通（含同意任务的 `approval:task`）。

### 怎么开启

在 zcode 对话里说：

- 「开始轮询合同审批风险」
- 「跑一下合同审批风险预审」

它会先自检，通过后立即处理当前待办，并按约定定时继续（建议每天 10:00 / 14:00 / 16:00，或固定间隔）。想停就说「停止轮询」。

### 几个要点

- **只处理待办**：已放行/驳回的不动；放行后任务从待办消失，天然不会重复处理。预审完成后的**人工审批节点**（如果预审账号也在会签名单里）AI 不会代签，留给审批人人工处理。
- **电脑要开机**：轮询跑在发起电脑上，**关机就停**，下次开机继续。
- **费用**：主体核对 0 元；90 天内查过的公司 0 元（用存档）；新公司约 7.5 元；自然人 0 元。
- **主体不一致会被拒**：这是唯一会自动拒绝的情况，目的是让提交人改对表单再走流程。**风险高低本身不拦截**——高/中/低风险都放行给法务判断，报告里命中项已黄色高亮，注意别遗漏。
- **合同附件请传 Word 或 Word 导出的 PDF**：扫描件和图片 AI 读不出来，会退回「请法务人工核对」。
- **别往「风险报告附件」传文件**：那是 AI 放报告的位置，传了会在预审时被删掉。

## 六、安全须知

- **不要把查询结果、Excel、配置文件（`.env`）发给公司外的人**。企查查数据只用于内部风控，不能二次分发。
- **`.env` 里有密钥**，只放在你自己电脑的技能目录里，不要截图发群、不要传网盘。
- 看到报错，把提示原文发给 IT，不要自己改代码或配置。

## 七、常见问题

**Q：审批被「风险预审拒绝」退回了怎么办？**
A：这说明**合同文件里实际签约的对方**和表单里选的企业不是同一家（拒绝评论里写了双方名称）。让提交人核对合同，把表单里的客户名称/供应商名称/达人企业名称改成合同上真实的那家（或换正确的合同附件），重新提交即可，重新提交不会重复扣费。

**Q：评级栏写着「合同主体未能自动校验，请法务人工核对」？**
A：AI 读不了这份合同附件（常见原因：扫描件、图片、附件没传）。请人工打开合同确认签约对方是否与表单一致，再继续审批。想根治就让提交人传 Word 或 Word 导出的 PDF。

**Q：技能页里没看到这两个技能？**
A：找 IT，让 IT 用 GitHub 地址重新装。

**Q：跑起来报「缺凭据」「MySQL 连不上」「企查查失败」？**
A：把提示原文发给 IT，一般是 `.env` 没填好或网络问题，不要自己改。

**Q：查出来的风险等级和我想的不一样？**
A：风险分级规则是法务部定的（见《配置说明》引用的规则表）。如果想调阈值，找法务负责人和 IT 一起改，不要自己改。

**Q：轮询提示「查询预审账号待办失败」或扫不到审批单？**
A：找 IT 核对 `.env` 里 `FEISHU_APPROVER_USER_ID`（及 `_TYPE`）是不是预审账号的正确 ID；再确认审批流里「系统风险预审」节点的审批人就是该账号。不要自己改别的配置。

**Q：定时扫描没跑？**
A：检查电脑是不是开着、zcode 是不是登录着。关机或 zcode 没开，扫描就停。

**Q：想给某张已经评过的合同重新评一次？**
A：在 zcode 里说「重新评一下审批 xxx 的风险」，把审批实例号给 IT 或自己填。
