# 法务操作说明书

> 写给法务部同事。你不需要任何开发经验，只要会打开 zcode、会打字就行。
> 如果遇到本说明书没覆盖的问题，把屏幕上看到的提示原文发给 IT，不要自己改代码或配置。

---

## 一、我们装了哪两个技能

| 技能 | 中文名 | 一句话作用 |
|---|---|---|
| `legal-company-query` | 企业风险查询 | 你说一个公司名，它帮你查这家公司的工商信息和风险等级，并生成一份 Excel |
| `legal-approval-risk` | 合同审批风险预警 | 自动扫描飞书里「待审批」的合同，把对方公司的风险评到审批评论区，并附一份 Excel |

两个技能都接企查查，查的是真实企业数据。

---

## 二、第一次用之前

这些**只需要做一次**，一般由 IT 帮你弄好：

1. 电脑装好 zcode 并登录。
2. 电脑装好 Python 3.11（没有就让 IT 装，按《配置说明》里的步骤，勾选 Add to PATH）。
3. 两个技能已经在 zcode 的「技能」页里出现（IT 用 GitHub 地址装的）。
4. 每个技能文件夹里有一份填好的 `.env`（IT 私下发给你，**不要外传**）。

如果技能页里没看到这两个技能，或 `.env` 没到位，先找 IT，不要自己猜。

## 三、企业风险查询（legal-company-query）

### 什么时候用

- 签约前想了解一家公司靠不靠谱
- 想看一家公司的工商信息、三要素是否一致、有没有涉诉/失信/被执行
- 同事问「这家客户能合作吗」

### 怎么说

直接在 zcode 对话里用自然语言说就行，例如：

- 「查一下上海帮麦麦网络科技有限公司的风险」
- 「这个客户靠谱吗：成都白兔有你文化传播有限公司」
- 「帮我看看这家企业的风险：xxx」

### 你会看到什么

1. **如果公司名有重名**：会先列出几个候选公司（带编号、信用代码、法人、状态），你回复一个编号选定。
2. **选定后**：会告诉你这家公司的——
   - 名称、统一社会信用代码、法定代表人、登记状态
   - 三要素是否一致（一致 / 不一致 / 未核验）
   - 风险等级：**低 / 中 / 高 / 未知**
   - 命中了哪些风险项（一条条列出）
   - 本次花了多少钱（已查过的一般 0 元，新查约 7.5 元）
3. **Excel**：会自动生成一份 `qcc_公司名_时间.xlsx`，放在本机技能目录里。你直接打开看明细。

### 几个要点

- **同名公司**：先选编号，别选错。
- **想查最新数据**：说「重新查」「查最新」「刷新一下」，会强制拉最新（约 7.5 元）。
- **已查过的公司**：默认用上次结果，不花钱；想看最新就说「查最新」。
- **Excel 路径**：结果里会给完整路径，找不到就让 IT 帮你打开。

## 四、合同审批风险预警（legal-approval-risk）

### 什么时候用

- 你希望待审批的合同一进来，就自动有风险提示
- 想让审批人在审批界面直接看到对方公司的风险

### 它怎么工作

这个技能是**定时自动跑**的，不需要你每次手动说。它会：

1. 扫描飞书里**待审批（PENDING）**的合同审批。
2. 读表单里已经选好的对方公司。
3. 查企查查最新风险，给出低/中/高等级。
4. 在那条审批的**评论区**写一条简短预警 + 一份 Excel 附件。

### 评论区会写什么

评论很短，只有这几行：

```
查询日期：2026-08-24 21:43:42
风险评级：低
风险命中项：
- 无命中项

完整风险信息见附件 Excel
```

明细全部在附件 Excel 里，点开附件看。

### 怎么开启定时扫描

在 zcode 对话里说：

- 「开始轮询合同审批风险」
- 「定时扫一下待审批合同，把风险评到评论区」

它会先自检，通过后开始定时跑。默认建议每天 10:00 / 14:00 / 16:00 三个时间点，或每 4 小时一次。你想停就说「停止轮询」。

### 几个要点

- **只处理待审批的**：已经通过/驳回的不动。
- **同一单只评一次**：不会重复发评论。
- **电脑要开机**：定时扫描跑在你的电脑上，**关机就停**，错过的时间点跳过，下次开机继续。
- **每单约 7.5 元**：每张新合同都会查一次最新（约 7.5 元），因为要给审批人最新风险。
- **高风险只是提示**：技能不会自动拦截或放行，是否继续由审批人判断。

## 六、安全须知

- **不要把查询结果、Excel、配置文件（`.env`）发给公司外的人**。企查查数据只用于内部风控，不能二次分发。
- **`.env` 里有密钥**，只放在你自己电脑的技能目录里，不要截图发群、不要传网盘。
- 看到报错，把提示原文发给 IT，不要自己改代码或配置。

## 七、常见问题

**Q：技能页里没看到这两个技能？**
A：找 IT，让 IT 用 GitHub 地址重新装。

**Q：跑起来报「缺凭据」「MySQL 连不上」「企查查失败」？**
A：把提示原文发给 IT，一般是 `.env` 没填好或网络问题，不要自己改。

**Q：查出来的风险等级和我想的不一样？**
A：风险分级规则是法务部定的（见《配置说明》引用的规则表）。如果想调阈值，找法务负责人和 IT 一起改，不要自己改。

**Q：定时扫描没跑？**
A：检查电脑是不是开着、zcode 是不是登录着。关机或 zcode 没开，扫描就停。

**Q：想给某张已经评过的合同重新评一次？**
A：在 zcode 里说「重新评一下审批 xxx 的风险」，把审批实例号给 IT 或自己填。
