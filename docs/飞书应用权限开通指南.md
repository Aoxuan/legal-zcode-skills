# 飞书应用权限开通指南

> 致：飞书管理员 / IT
> 目的：让「合同审批风险预警」技能能用应用身份读取审批、在审批评论区写风险预警；并让申请人在合同审批表单里就能搜企业、选风险评级。
> 你要配合 **两件独立的事**，做完一件不等于另一件生效：


| 工作               | 在哪做    | 目的                | 怎么算做完                    |
| ---------------- | ------ | ----------------- | ------------------------ |
| **工作一：开通自建应用权限** | 开发者后台  | 技能能用应用身份读审批、写评论   | 应用三条 scope 已开通且最新版本已发布通过 |
| **工作二：调整合同审批表单** | 审批管理后台 | 申请人能在表单里搜企业、选风险评级 | 两个外部选项单选配好并发布审批定义新版本     |


两件事在两个后台、走两套发版，互不影响：

- 工作一在「开发者后台」发**应用版本**；工作二在「审批后台」发**审批定义版本**。
- 工作一不需要机器人、不需要消息事件、不需要 webhook、不需要公网地址（技能是定时轮询，应用身份调用）。
- 工作二要填的 URL / Token 是**我方已部署的中转适配器**，不是企查查开放平台地址，也不是 App Secret。企查查账号密钥只放在我方运行机的 `.env`，不进飞书后台。

---

## 工作一：开通自建应用权限

### 1.1 创建或复用自建应用

1. 打开 [open.feishu.cn](https://open.feishu.cn)，登录进入「开发者后台」→「企业自建应用」。
2. 可复用现有自建应用，或新建一个。建议命名清晰，例如「法务合同小助手」。
3. 在「凭证与基础信息」记下 **App ID** 与 **App Secret**，私发给 法务 写入技能的 `.env`。



### 1.2 开通权限（权限管理 → 添加应用身份权限）

只需这三条：


| 权限 scope                          | 用途             | 必需  |
| --------------------------------- | -------------- | --- |
| `approval:approval.list:readonly` | 查询审批实例列表（扫待审批） | 必需  |
| `approval:approval:readonly`      | 读取审批实例详情与表单    | 必需  |
| `approval:approval`               | 创建审批评论（含上传附件）  | 必需  |




### 1.3 保存 → 创建版本 → 发布 → 审批

> 改权限后**必须**走完发版流程，否则不生效。

1. 权限页点「保存」。
2. 应用首页「创建版本并发布」。
3. 租户管理员审批通过。
4. 「应用可用范围」配置：法务部 + 需要跑技能的电脑对应账号（技能用应用身份调用，可用范围要覆盖应用本身）。



### 1.4 把以下信息交给 法务（写入 `.env`）


| 项                                     | 怎么取                                           |
| ------------------------------------- | --------------------------------------------- |
| `FEISHU_APP_ID` / `FEISHU_APP_SECRET` | 凭证与基础信息页                                      |
| `FEISHU_APPROVAL_CODES`               | 打开合同审批定义，浏览器地址栏 URL 里的 `approvalCode`；多个用逗号分隔 |
| `FEISHU_FIELD_COMPANY`                | 表单里「对方企业名称」那一个外部选项的控件名（见工作二）。                 |
| `FEISHU_COMMENT_USER_ID`（可选）          | 部分租户写评论必须指定发表人。需要时给一个法务账号的 `open_id`；不要时留空    |
| `FEISHU_COMMENT_USER_ID_TYPE`（可选）     | 默认 `open_id`，可填 `user_id` / `union_id`        |




### 1.5 如果写评论失败

常见两种情况：

1. **提示要发表人**：该租户要求评论指定发表人。给一个法务账号的 `open_id`，IT 写入 `FEISHU_COMMENT_USER_ID`。
2. **提示无权限**：回到 1.2 确认三条 scope 都开通且已发版通过；确认应用可用范围覆盖。

把报错原文发给 IT，不要自己改。

### 1.6 工作一怎么检验

1. 开发者后台该应用「权限管理」能看到这三条已开通，且**最新版本已发布通过**。
2. 把 App ID / App Secret / `approvalCode` 私下交给 法务，法务 写入 `.env` 后（1）在技能目录跑 `py scripts/poll.py check`，输出 `ok` 为 `true`。
3. 有一张待审批合同时，法务 干跑或正式轮询一次：能读到表单里的对方企业，评论区出现风险预警（或干跑日志显示将要写评论）。读不到 / 写不了，按 1.5 排查，**不要去改表单**。

## 工作二：调整合同审批表单

> 在「审批管理后台」编辑「合同申请」审批定义，**不要和开发者后台混在一起**。
> 需要新增 / 改造两个单选控件，都接我方已部署的中转适配器。两个控件用**同一串 Token**。

适配器地址（已部署，照填即可）：

- 企业名称搜索：`http://101.96.217.199:12000/feishu/approval/external-options/company`
- 企业风险评级：`http://101.96.217.199:12000/feishu/approval/external-options/risk`

Token：麦麦熊猫IT提供，与适配器 `.env` 的 `FEISHU_EXTERNAL_OPTIONS_TOKEN` 同一串；两个控件填**同一串**。不要写真实值进截图、不要发聊天群。

### 2.1 把「对方企业名称」改为单选 + 外部数据源

- 控件名：**对方企业名称**（若现有字段叫「对方单位名称」或是输入框：改成下面的单选，显示名改为「对方企业名称」）。
- 类型：单选；**必填**；禁止手填自由文本。
- 选项来源：使用外部选项；处理方式 **V2（支持模糊、分页搜索）**。
- URL：`http://101.96.217.199:12000/feishu/approval/external-options/company`
- Token：IT 提供的那一串（与适配器一致）
- Key：**留空**（本期不加密）

**2.1 怎么检验**

- 设计器点「校验接口」：能通过即可（空关键词会回空列表，这是正常的，不要当成失败）。
- 保存后用测试账号**真发起一张合同审批**（不要只信校验按钮）：在「对方企业名称」输入「顶呱呱」或「讯格得」，应弹出候选，展示为 `名称｜信用代码｜法人`，点选一家后能带上选中值。
- 失败常见原因：URL 填成企查查地址、Token 与适配器不一致、审批定义未发版、适配器关机。把报错原文给 IT，不要自己改 Token 以外的项。



### 2.2 新增「企业风险查询」单选 + 外部数据源

- 同一张表单新增，**不要另起审批定义**。
- 控件名：**企业风险查询**
- 类型：单选；**必填**。
- 选项来源：外部选项 V2。
- URL：`http://101.96.217.199:12000/feishu/approval/external-options/risk`
- Token：与「对方企业名称」**同一串**；Key 留空。
- **联动参数**（两格都要填，缺一格会报「附加字段或代码不能为空」）：
  - 左：选 **对方企业名称**
  - 右「参数代码」填：`credit_code`
  - 飞书会 POST `linkage_params: {"credit_code": "<选中企业的 option id，即统一社会信用代码>"}`
- 控件说明建议写：**选完企业后点开；若暂时没有选项，等几秒再点一次。换企业后请重新点开。**

**2.2 怎么检验**

- 设计器「校验接口」：联动信用代码**必须留空**。立刻出现空列表 = 通过。**不要填真实信用代码**（会超过飞书 3 秒超时，看起来像接口坏了）。
- 真发起测试单：先选好企业，再点开「企业风险查询」。第一次可能没有选项（后台在查，约几秒、约 7.50 元），再点一次应出现一条 `低/中/高/未知风险｜…`。换一家企业后必须重新点开。
- 未选企业就点开：空列表、交不了单（必填挡住）即符合预期。
- 保存后必须 **发布审批定义新版本**，未发版则申请人仍是旧表单。
- 联调时顺便看一眼：改选企业后风险控件会不会被清空（应清空，需重新点开）。



### 2.3 工作二做完，把这些交给 法务/麦麦熊猫IT

- 两个控件的**最终显示名**（「对方企业名称」「企业风险查询」）。
- 写入 `.env` 的 `FEISHU_FIELD_COMPANY`（填「对方企业名称」控件名）。
- 浏览器「合同申请」URL的 `definitionCode`（地址栏里取，多个逗号分隔）。

## 安全提示

- App Secret 是密钥，只私发给 法务 写入运行机的 `.env`，不进 git、不进聊天群、不截图。
- 飞书表单里填的 Token 是我方适配器的校验串，**不是企查查 Key，也不是 App Secret**；同样不要截图、不要填进聊天群。
- 应用可用范围按需收敛到法务 + 跑技能的账号，不要开全员。
- 不开通本技能用不到的权限。
